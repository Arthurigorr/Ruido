# Ruido: A Streamline Package To Calculate Soundscape Saturation

<img src="man/figures/ruidoIcon.png" alt="Icon of Ruido" align="left" width = "25%" height="25%"/>

**Ruido** is an R package that aims to provide a simple and accessible framework for calculating less common soundscape metrics. It includes functions to estimate key acoustic indicators based on established methodologies. It includes functions for estimating Background Noise (BGN) and Soundscape Power (POW) following Towsey et al. (2014), as well as Soundscape Saturation (SAT) following Burivalova et al. (2021).

## Installation

Install the package directly from CRAN using:

``` r
## The package is not in CRAN yet
# Install the package
install.packages("Ruido")

# Load the package
library(Ruido)
```
